01

The idea

Participant tracking for graduation programs ran entirely on paper: ledgers carried house to house.

That system worked, but it didn't scale across a hierarchy: Program Organizer, Branch Manager, Regional Manager, and Finance Manager each needed a different view of the same data.

Built for Amplifier Strategies, digitizing a program running BRAC's Ultra-Poor Graduation approach.

The system before Impact Atlas: a handwritten paper form, tracked house to house.

02

The approach

The paper process already encoded a working hierarchy: Program Organizer collects, Branch Manaager verifies, Regional Manager analyzes, Finance Manager oversees.

Digitizing it meant preserving that real structure, not redesigning how the program worked.

Role-specific views, built directly from the user stories each role already lived by.

Role-specific views, mapped from the journey: click to open full PDF

03

Design research

Research started from the paper system already in use (weekly visit schedules, means-test forms, hand-tallied participant ledgers filled out in the field) and from direct conversation with the team about who needed to see what.

All field photos shot by me during the original program visits.

04

Design execution

Unlike the other case studies here, this one started on paper: a hand-drawn participant profile sketch, worked out before any digital tool touched it. User stories were written out role by role on a whiteboard, then mapped into a role/data architecture, before any of it moved into annotated wireframes with roles and edge cases called out directly on the frame.

From there, sketches became annotated wireframes: each screen tagged with the role it belongs to, edge cases called out directly on the frame, desktop and mobile covered separately.

05

What shipped

A participant profile view tracking graduation across 10 milestones, deployed across desktop, tablet, and mobile, localized into French and Arabic alongside English for the regions each program ran in.

06

Outcomes

Impact Atlas was built for a program running BRAC's Ultra-Poor Graduation approach, the same model behind the poverty ranking, means test, and participant selection stages this tool digitizes.

That approach has a strong track record: 95% of participants lift out of extreme poverty by program's end, and 93% still show those gains ten years later.

These are results from the methodology this program runs, not metrics from the tool itself, worth stating plainly rather than implying otherwise.
